# Full-stack Admin Dashboard — Learning Project

A MERN admin dashboard tutorial/reference project stored under `fullstack-admin-master/`.

## Contents
- `fullstack-admin-master/client/` — React dashboard
- `fullstack-admin-master/server/` — Node.js backend
- `fullstack-admin-master/README.md` — original project notes and tutorial reference

## Attribution
The nested README links to the original [MERN admin dashboard tutorial](https://www.youtube.com/watch?v=0cPCMIuDk2I). This repository is presented as tutorial/reference-based learning work rather than claimed as an independently designed production product.

## Setup
Inspect the package scripts and environment requirements inside `client/` and `server/`. Install their dependencies separately and configure a local database before starting the two applications.
